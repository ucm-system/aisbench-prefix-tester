# UX 审计报告 — AISBench 前缀复用测试器

> 审计对象：`D:\pt-release\win-unpacked`（2026-09-21 最新包）+ main 分支源码
> 审计方法：pmaster（KANO 需求分类 / RICE 优先级 / 用户旅程）+ ui-ux-pro-max 规则库（可及性/表单反馈/布局栅格）
> 证据：`docs/screenshots/ux-*.png`（1440×900 全页 + 1024×700 窄屏）
> 范围说明：本报告**不含**用户已提出的 8 组问题（模型目录/词表来源/采集端点联动/摘要栏空置/监控图表宽度与饼图/对比按钮位置/设置页诊断占比/SLA 布局截断），这些问题一并纳入《UX-REDESIGN.md》的整改方案。

## 一、用户旅程结论（pmaster 视角）

目标用户是「性能/推理测试工程师」。核心 Jobs-to-be-Done：
1. **连上服务，快速发起一次可信的压测**（当前断点：默认参数过重、命名不可发现、校验无反馈）
2. **运行中知道“现在发生了什么”**（当前断点：图表点稀疏、无阶段标记、日志噪音）
3. **运行后拿走结论并横向比较**（当前断点：结果只在日志 ASCII 表里、对比入口深、SLA 拐点无可视化）

产品可用性主线未断（能跑通全流程），但「结果可信度呈现」与「防呆」两层基本缺失——这正是工具类产品的期望型需求（KANO：做得好才满意的那类），当前普遍未交付。

## 二、问题清单（24 项，均为本报告新增）

优先级定义：P0=阻断/数据可信，P1=高频痛点，P2=明显摩擦，P3=打磨。

### A. 全局 / 信息架构

**A1 [P1] 监控页无常驻导航入口**
- 证据：侧栏仅 5 项（新建测试/运行记录/对比分析/设置/SLA 调优）；`#/monitor/<id>` 只能从顶栏临时提示或记录页进入；run 结束后顶栏提示消失，回放入口深埋。
- 整改：导航增加「运行监控」常驻项（无活动 run 时显示最近一次 run 的回放）；活动 run 存在时导航项加绿点+run 名徽标。见重设计文档 §3。
- KANO：期望型。

**A2 [P1] 「数据集」页面在打包版中不可达**
- 证据：源码存在 `DatasetPage.tsx`（数据集入库/复用），打包版导航无入口；配置页「复用已入库数据集」下拉成孤儿功能。
- 整改：恢复导航入口「数据集库」，或在配置页第 2 区内嵌「我的数据集」管理卡片（列表+删除+预览）。
- KANO：期望型（数据集复用是长测场景刚需）。

**A3 [P2] 深链/刷新后无上下文与回退路径**
- 证据：hash 路由直接打开 `#/monitor/<id>` 时侧栏无高亮项、无面包屑；浏览器/应用内无「返回列表」动线。
- 整改：每个详情页顶部加面包屑（运行记录 / run_id）；侧栏按路由前缀高亮（monitor 归入「运行监控」）。

**A4 [P3] 品牌资产缺失**
- 证据：侧栏 logo 为文字「PC」，与应用无关联；favicon 404（浏览器控制台报错）。
- 整改：产出应用图标（前缀缓存隐喻：层叠块+命中高亮），输出 ico/png 多尺寸，替换侧栏 logo 与窗口图标。

**A5 [P2] 中英混排与术语不统一**
- 证据：图表标题「Prefix Cache Query Breakdown」为英文，其余全中文；「HBM 命中率 / Ext 命中率 / 综合」无 tooltip 解释口径（Δhits/Δqueries）。
- 整改：建立术语表（HBM→显存命中，Ext→外部缓存命中，综合→复合命中率），图表标题中文化，指标卡 hover 显示口径公式与采集来源（vllm:/ucm: 指标名）。

**A6 [P2] 键盘与可及性未覆盖**
- 证据：全部交互仅按鼠标路径设计；表格无键盘导航；自绘图表无 aria 标签；彩点图例仅靠颜色区分（色弱不可辨）。
- 整改：表单 Tab 顺序治理 + 焦点环样式；图表加 `<title>`/aria-label；图例加形状区分（实线/虚线/点线）。依 ui-ux-pro-max 优先级 1（可及性 CRITICAL）。

### B. 新建测试页

**B1 [P0] 「校验配置」无任何反馈**
- 证据：点击后无 toast、无红字、无成功标识（对照「探测」按钮有 ✓ 反馈）。ui-ux-pro-max Forms 规则：Submit Feedback 缺失属 High 严重度。
- 整改：校验通过→绿色成功条「配置可用，可开始测试」；失败→错误摘要条（可点击滚动至出错字段）+ 字段级红框与错误文案。统一 toast 组件。

**B2 [P1] 运行命名入口不可发现**
- 证据：唯一命名入口是多轮表格第一行「名称」格；列表页大量「run 2026/9/21 13:15:12」。pmaster：命名是回溯/对比的前置数据。
- 整改：表单顶部第一行放「运行名称」输入框（placeholder 给示例：「qwen3-8101-90%重复-c4」），轮次名称仍可单独覆盖；提交时若为空给出建议名并允许就地修改。

**B3 [P1] 无配置预设/模板**
- 证据：页头写「配置 · 预设 · 数据集」但页面无预设能力；每次打开回到 192.168.1.10:8000/input 32768 默认值；上次填写的配置不记忆。
- 整改：①表单草稿自动保存（localStorage，按最后输入恢复）；②「保存为预设」+ 预设下拉（内置：快速冒烟/标准测试/PD 分离）；③默认值改轻量（input 2048/output 32/data 16/conc 8），避免新手一上来压垮服务。

**B4 [P1] 数值输入无边界与联动校验**
- 证据：input_len 可填任意大值，与目标服务 `max_model_len`（探测可获取）无校验；output_len/data_num/concurrency 无上限提示；错误要跑到 ais_bench 阶段才暴露。
- 整改：探测成功后记录 max_model_len/max_num_seqs，字段失焦即时校验（input_len+output_len ≤ max_model_len），超限红字并给出建议值。

**B5 [P2] 「探测」结果信息一次性和未回填**
- 证据：探测成功仅一行小字「✓ 服务可达 · /metrics 可达 · 模型: qwen3」；不展示模型列表、上下文长度、是否 UCM；不回填采集端点。
- 整改：探测后渲染「服务信息卡」（模型、max_model_len、metrics 端点、ucm 检测、版本），提供「一键填入采集端点」按钮。

**B6 [P2] 采集端点文本框无逐行校验与测试**
- 证据：2 行小 textarea；格式错误只有后端报错；无「测试连通」按钮；PD 多端点场景要手填多行。
- 整改：端点 chip 化（回车添加、可删除），每行带可达性小圆点（自动 ping /metrics），保留批量粘贴。

**B7 [P2] 长度分布的参数区不可见即失效**
- 证据：选「高斯 mean±std / 均匀 min–max」后参数输入不明显，未填参数无提示，提交后行为不可预期。
- 整改：切换分布时内联展开对应参数输入并标必填；未填则校验拦截。

**B8 [P3] 轮次表格缺常用操作**
- 证据：无「复制上一轮」、无「恢复继承」快捷、删除行无确认；JSON 模式错误只有后端报错。
- 整改：行 hover 出现复制按钮；覆盖过的单元格提供一键清空回「继承」；JSON 模式前端先 parse 校验再提交。

### C. 监控页

**C1 [P0] 图表无 tooltip / 无缩放 / 无导出**
- 证据：自绘 SVG 无悬停数值提示；无法查看某时刻精确值；不能导出数据。工具类产品「取数」是核心 JTBD。
- 整改：所有图表加十字线 tooltip（时间+各序列值）；支持框选缩放与双击复位；提供「导出本 run 时序 CSV」（后端已有 JSONL，前端转存即可）。

**C2 [P1] 阶段边界与事件在时间轴上不可见**
- 证据：warmup→full 切换、cache reset、轮次切换在图表上无标记；命中率突变无法归因。
- 整改：阶段边界画垂直虚线+顶部小标签（R1 warmup / R1 full）；事件（reset 成败、SLA 探针切换）在时间轴打点。

**C3 [P1] 多轮运行的时序混在一条轴上**
- 证据：rounds>1 时所有轮数据连续画在同轴，无分隔。
- 整改：按轮分色或加轮次分隔带；图表图例显示轮次开关，可聚焦单轮。

**C4 [P1] KPI 卡无参照基准**
- 证据：命中率 83.3% 无「理论命中率 ≈89.992%」参照；TTFT 无 SLA 阈值线。
- 整改：命中率卡副行显示理论值与偏差；TTFT/吞吐卡支持叠加 SLA 参考线（读 SLA 页最近配置）。

**C5 [P2] 日志区缺搜索/过滤增强与 stderr 入口**
- 证据：只有 全部/WARN/ERROR 三个过滤 + 跟随滚动 + 导出 stdout；无法搜索 run_id/关键字；stderr 不可见；tqdm 进度行未折叠。
- 整改：增加关键字过滤与「折叠进度行」开关（正则 `Progress:|POST=|Calculating`）；stderr 单独 tab；导出支持 stdout/stderr/合并。

**C6 [P2] 断线/重连无状态提示**
- 证据：WS 断开后图表静默停更；仅侧栏「Sidecar ● 已连接」一处弱提示。
- 整改：WS 断开时监控页顶部出现黄色横幅「实时连接中断，正在重连…」，恢复后自动补拉缺失时序。

**C7 [P2] 「停止测试」无确认且终态区分弱**
- 证据：停止直接生效；停止后与失败在记录列表中颜色相近（灰 vs 红）。
- 整改：停止加确认弹层（说明将丢弃未完成轮次）；「已停止」用黄色徽标，与「失败」红色区分。

**C8 [P3] run 头部信息薄**
- 证据：只有 run_id/时间/状态/轮次；无耗时、无数据集摘要（条数/前缀/重复率）、无「导出报告」直达。
- 整改：头部第二行展示 关键参数 chips（模型/输入/输出/并发/重复率）+ 耗时 + 导出按钮。

### D. 运行记录页

**D1 [P1] 行内 4 个常驻操作按钮，删除红字每行可见**
- 证据：23 行 × 4 按钮（监控/详情/xlsx/删除），视觉噪音大；删除无二次确认，误触即删数据。
- 整改：行 hover 才浮出操作；删除走确认弹层（输入 run 名或二次点击）；顶栏批量操作保留。ui-ux-pro-max：破坏性操作必须可逆/需确认。

**D2 [P2] 过滤维度不足**
- 证据：只有 手动/SLA/全部 + 搜索框；无状态筛选（失败/已完成/已停止）、无时间范围。
- 整改：筛选条增加「状态」多选 chips；记录>50 条启用分页或虚拟滚动。

**D3 [P2] 详情抽屉遮挡工具栏且导出被锁在抽屉里**
- 证据：抽屉打开后「对比所选/删除所选」被拦截无法点击；导出按钮只在抽屉内。
- 整改：抽屉改为右侧 Drawer（固定 480px，带遮罩，ESC/点遮罩关闭），不覆盖顶部工具栏；列表行内保留快捷导出。

### E. 对比分析页

**E1 [P2] 空状态与结果区缺少结构**
- 证据：未对比时右侧整片空白仅一条提示；对比后指标表/每轮矩阵/DP 矩阵/配置 diff 全部纵向堆叠在下方，无锚点。
- 整改：结果区加 tab 锚点（指标总览/逐轮对比/DP 矩阵/配置差异）；空状态给出图示化引导。

**E2 [P1] 对比结果无可视化**
- 证据：只有表格 + Δ%（abs/pct/good 三色），无柱状对比图；pmaster 视角：对比的价值在「一眼看出差异」。
- 整改：核心指标（TTFT P50/P90、吞吐、命中率）渲染成对柱图（run A vs run B），delta 标注在柱顶；多 run 用分组柱。

**E3 [P2] 练习轮排除逻辑不透明**
- 证据：「排除练习轮」默认勾选，但列表里练习轮标签弱（小灰字），用户不知道某些 run 为何「选了却不参与」。
- 整改：被排除项在列表中半透明+「已排除」徽标，悬停说明原因；顶部显示「已排除 N 个练习轮」。

### F. SLA 页

**F1 [P1] 调优过程无进度可视化**
- 证据：开始后仅表格逐行追加探针行；无「当前并发 / 二分区间 / 预计剩余」，无醒目取消入口。
- 整改：结果卡顶部加进度条与阶段文案（「爬升中 c=32」「二分 [64,128]」）+「停止调优」按钮；探针行实时高亮当前行。

**F2 [P0] SLA 结果无「并发-延迟」曲线**
- 证据：探针表只有数字；产品的核心结论（拐点在哪）需要看图。
- 整改：结果区渲染 双轴曲线（x=并发，左 y=TTFT P90/TPOT，右 y=吞吐），SLA 阈值画横线，命中区间绿色填充，拐点标注「SLA 内最大并发 = N」。

**F3 [P2] 历史调优选中态与详情联动不清**
- 证据：点击历史行加载详情，但结果卡是否被覆盖、选中了哪一行无视觉反馈。
- 整改：历史行选中高亮；结果卡标题显示「查看：2026/9/21 07:57:06」并给「返回最新」。

### G. 设置页

**G1 [P2] 采集间隔两处配置，生效关系不明**
- 证据：设置页有 2s/5s/10s/30s；新建测试配置里也有 collection_interval；谁覆盖谁无说明。
- 整改：设置页改为「新 run 的默认采集间隔」，run 内不可改；在两处互相标注来源（「默认值，单次 run 可在新建测试覆盖」）。

**G2 [P3] Tokenizer 资产注册后无管理列表**
- 证据：注册输入框+按钮，注册成功后在哪看到/删除不可知。
- 整改：注册下方列出已注册目录（含来源：内置/本机扫描/手动），可移除、可测试加载。

**G3 [P3] 重启 Sidecar 无确认与进行中状态**
- 证据：点击即重启；重启期间页面无反馈，恢复无提示。
- 整改：确认弹层 + 按钮进入 loading + 完成后 toast；若活动 run 存在则警告「将中断当前 run」。
